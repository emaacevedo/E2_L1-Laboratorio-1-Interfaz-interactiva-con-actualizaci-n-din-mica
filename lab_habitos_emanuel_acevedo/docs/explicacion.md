Se utilizó un Scaffold con AppBar para la estructura principal, seguido de un Column dentro de un Padding para ordenar verticalmente los elementos. El bloque de portada se construyó con un Container y un Icon para representar la imagen del curso con altura y borde redondeado. Para el título y el docente se usaron Text con diferentes tamaños y colores para establecer jerarquía visual. La información del curso se organizó en un Row con dos contenedores de texto para mostrar duración y nivel. Finalmente, se empleó un ElevatedButton como acción principal para la inscripción. La elección de estos widgets permite mantener una interfaz clara, ordenada y fácilmente escalable.
